# Hide Scene Tabs in Script Mode

Godot 4.7 editor plugin. Hides the open-scene tab bar in the Script workspace and shows it again in 2D, 3D, Game, and Asset Store. Scenes stay open, so viewport zoom and position are kept.

## Install

Copy `addons/hide_scene_tabs` into your project's `addons` folder. Enable **Hide Scene Tabs in Script Mode** under Project > Project Settings > Plugins.

This repository is already a Godot project with the plugin enabled.
